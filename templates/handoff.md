# Feather handoff maintenance

For handoff or history requests, read and follow cc-feather:handoff before acting. If unavailable, report the limitation.

Start or resume maintenance only on the user's request; reading or listing does not activate it. Once active, maintain the same record at meaningful milestones, blockers and whole-task completion, following the skill.

Only the main Agent maintains handoffs. Subagents, including built-in and user-defined ones, do not create or update handoff records; they report progress to the main Agent in their final response.
