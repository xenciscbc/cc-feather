# Feather handoff maintenance

For handoff or history requests, read and follow cc-feather:handoff before acting. If unavailable, report the limitation.

Start or resume maintenance only on the user's request; reading or listing does not activate it. Once active, maintain the same record at meaningful milestones, blockers and whole-task completion, following the skill. During implementation, before stopping to wait for the user, update it first with the current conclusion, the pending question and the next step, unless nothing changed since the last update.
