# Pilotfish 啟用機制查核

查核基準：GitHub `main` 的 `4b35ad6ef0de7b1e3966c2b96f05c99af4aba702`；Plugin manifest 標示版本 `1.4.1`。[manifest](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/plugin/.claude-plugin/plugin.json)

## 已確認事實

- **Plugin 的自動啟用入口是 `SessionStart` hook。** `plugin/hooks/hooks.json` 只註冊一個 command hook，matcher 為 `startup|resume|clear|compact`，透過 `/bin/sh` 執行 `${CLAUDE_PLUGIN_ROOT}/hooks/emit-sessionstart.sh`。[hooks.json](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/plugin/hooks/hooks.json) 官方文件說明 `SessionStart` 這些來源各指新會話、恢復、`/clear`、壓縮；成功 hook 的純文字 stdout 會加入 Claude 的上下文。[Claude Code hooks](https://code.claude.com/docs/en/hooks#sessionstart)
- **腳本做相容性探測後輸出提示詞。** 若 `CLAUDE_CODE_SUBAGENT_MODEL` 非空、設定根目錄不安全，或有效的使用者 `CLAUDE.md` 有 Pilotfish 舊版標記，腳本只輸出診斷文字並以 0 結束；其餘情況 `cat` 輸出 `plugin/policy/sessionstart.txt`。它不改設定、不自行呼叫代理，也沒有在此定義工具呼叫攔截。[emit-sessionstart.sh](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/plugin/hooks/emit-sessionstart.sh) 該文字把 `SessionStart` 描述為持續性 opt-in，要求主代理判斷任務形態、風險、計畫、批准與角色呼叫；明說本身不授予工具、寫入或其他權限。[sessionstart.txt](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/plugin/policy/sessionstart.txt)
- **執行層與指令層要分開看。** 已註冊的 hook 確定會在符合事件時執行，前述探測會決定是否輸出政策；輸出的工作流程是讓模型遵循的上下文，並非 `PreToolUse` 等攔截器。Claude Code 官方明確區分：`CLAUDE.md`／skill 的禁令是請求，封鎖工具需相應 hook；此 Plugin 的 manifest 只有 `SessionStart`。[hooks.json](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/plugin/hooks/hooks.json) [Claude Code extension guide](https://code.claude.com/docs/en/features-overview#compare-similar-features) 安裝文件另指出唯讀角色依賴 Claude Code 原生 agent `tools` allowlist，並要求 2.1.219 以上；那是 agent 工具配置的邊界，不表示主流程所有政策都有程式性強制。[Plugin install](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/install/PLUGIN-INSTALL.md)
- **安裝路徑不同。** Plugin beta 透過 user-scope marketplace 加入／安裝，需接受 hook 並重啟，因為當前 Claude Code 行程不會因安裝而立即啟用 hook；Plugin 提供七個 `pilotfish:<role>` 命名空間代理，不帶舊版對內建 `Explore` 的覆寫。[Plugin install](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/install/PLUGIN-INSTALL.md) 舊版全域安裝則直接寫有效設定根目錄下的 `settings.json`、`agents/*.md`、`CLAUDE.md` 政策區塊。[README](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/README.md) Plugin 的舊版標記檢查僅停止**新政策輸出**，不會停掉 Claude Code 會話或移除已載入的舊版 `CLAUDE.md`。[emit-sessionstart.sh](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/plugin/hooks/emit-sessionstart.sh)
- **`/pilotfish <task>` 是另一條可選啟動捷徑。** `install/ACTIVATION-INSTALL.md` 要先有舊版全域安裝，才另外建立使用者 skill；其 frontmatter 設 `disable-model-invocation: true`，由使用者手動呼叫並用 `$ARGUMENTS` 傳任務。可選 CLI wrapper 以 `--append-system-prompt` 啟動。文件說兩者是明示 opt-in，未分別驗證其派工可靠性／頻率，也說 `pilotfish-auto` 未提供、`UserPromptSubmit` hook 未採用。[Activation install](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/install/ACTIVATION-INSTALL.md) [Skill payload](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/install/ACTIVATION-INSTALL.md)

## 推論與限制

- **推論：** Plugin 的「自動」是每逢匹配的會話事件，自動把政策提示詞交給主模型；不保證主模型實際派工。專案 README 自承較高優先序指令可抑制 Agent dispatch，也不聲稱自發派工有保證。[README](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/README.md)
- **未覆蓋情形：** Claude Code 現行文件另列 `fork` 事件來源，但此 Plugin matcher 沒列 `fork`；依宣告推論，新版 fork 會話不會由此 hook 注入政策，未做實機驗證。[hooks.json](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/plugin/hooks/hooks.json) [Claude Code hooks](https://code.claude.com/docs/en/hooks#sessionstart) Plugin beta 僅宣稱 macOS 實機觀察；Linux 只符合契約、未實測，Windows 排除，亦不保證跨版本穩定或執行時命名衝突不存在。[Plugin install](https://github.com/Nanako0129/pilotfish/blob/4b35ad6ef0de7b1e3966c2b96f05c99af4aba702/install/PLUGIN-INSTALL.md)

驗證：閱讀上述 pinned 原始檔、官方 Claude Code hooks 文件與儲存庫 `tests/test_plugin_hook.py` 的測試案例；未安裝 Plugin、未執行 Claude Code 實機派工。後續若需判定特定使用者環境是否真的注入，最小檢查是於支援的 macOS／Linux Claude Code 中核對已啟用 Plugin、hook 狀態與 debug log。
